# Digital Portfolio

My personal site: [tanisharajgor.github.io/digital-portfolio](https://tanisharajgor.github.io/digital-portfolio/)

Built from scratch with React and Tailwind CSS. The space theme (orbiting rocket, spinning Earth, canvas starfield with shooting stars) is all hand-written.

## Running locally

```bash
npm install
npm start        # dev server at http://localhost:3000
npm test         # run tests
npm run deploy   # build and publish to GitHub Pages
```

## Editing content

- **Projects:** `src/data/projects.js`, one object per card (title, link, description, tags)
- **Experience terminal:** `src/data/experience.js`
- **Bio and community links:** `src/App.js`
- **Skills marquee:** `src/components/skills.js`
